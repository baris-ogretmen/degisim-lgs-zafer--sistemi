Anahtar Merkezi

Yapay zekâ özellikleri okulun ortak anahtarıyla çalışır; genelde bir şey yapmana gerek yoktur. Kendi ücretsiz anahtarını da ekleyebilirsin:

1️⃣ aistudio.google.com/apikey → Google ile gir
2️⃣ Create API key → AIza… anahtarını kopyala
3️⃣ ⚙️ Ayarlar → anahtar kutusuna yapıştır → Kaydet
🔒 KVKK / Gizlilik: Anahtarlar yalnızca yapay zekâ isteklerinde kullanılır; kişisel verilerin reklam vb. amaçla paylaşılmaz. Ortak anahtar cihazına kalıcı kaydedilmez, buluttan gelir. Kendi anahtarını girersen yalnızca kendi cihazında saklanır.

❓ Ücretsiz API anahtarı nasıl alınır? (adım adım)
Neden gerekli? Uygulamadaki yapay zekâ özellikleri (konu anlatımı, test üretimi, Hoca sohbeti, kavram kartı) Google Gemini ile çalışır. Ücretsiz anahtar = ücretsiz, kişisel kota. Not: Okulun Ortak Anahtarı tanımlıysa buna gerek kalmaz, AI zaten açıktır.

Adımlar:
1️⃣ aistudio.google.com/apikey adresine gir.
2️⃣ Google (Gmail) hesabınla giriş yap.
3️⃣ “Create API key / API anahtarı oluştur”a bas.
4️⃣ Çıkan AIza… ile başlayan anahtarı kopyala.
5️⃣ Buraya, yukarıdaki kutuya yapıştır → Kaydet. Bitti! ✅
